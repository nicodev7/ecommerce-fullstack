# E-Commerce Platform
A full-stack e-commerce application with a FastAPI backend and React frontend.
## Tech Stack
- **Backend:** FastAPI, SQLAlchemy, PostgreSQL, Redis, Docker
- **Frontend:** React, Vite, Tailwind CSS, Zustand, React Query
## Quick Start
```bash
# Backend (Docker)
cd ecommerce-api
docker compose up -d
# Frontend
cd ecommerce-frontend
npm install
npm run dev
